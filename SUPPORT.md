# Stocked Support

Email [support@sowensstudios.com](mailto:support@sowensstudios.com) with the Stocked version, device model, iOS version, and steps to reproduce the issue. Use the in-app QA report when available, but remove receipts, household codes, API credentials, and sensitive images before sending.

For account deletion, use **Settings → Account → Delete Account**. For a server-data request, use the subject **Stocked Data Request** and include the household/member identifier visible in Settings where available.
