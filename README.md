# Stocked

Stocked is a SwiftUI kitchen operating system for iPhone and iPad: inventory, groceries, receipts, recipes, meal planning, household sync, cooking tools, widgets, and optional intelligence in one app.

The app supports guest use and Sign in with Apple, private iCloud/CloudKit data, an App Group for widgets and sharing, and a Cloudflare Worker for authenticated household and intelligent features.
